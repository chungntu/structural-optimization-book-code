# Structural Optimization Book Code

This repository contains the source code examples used in the book **Co hoc ket cau cong trinh xay dung - Toi uu ket cau**.

## Structure

- `examples/`: code examples referenced directly from the book, grouped by chapter/example number.
- `legacy-octave/`: additional Octave/MATLAB scripts kept from the supporting material.

## Languages

- MATLAB / GNU Octave
- Python

## Notes

The code is organized to match the numbering used in the book. Some scripts may require MATLAB, GNU Octave, Python, or common scientific packages depending on the example.

## Vietnamese
